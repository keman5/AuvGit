# AuvGit 原生工作区视觉规范

本次范围：主窗口的仓库与分支导航、操作工具栏、文件列表、差异预览、紧凑历史、提交编辑器、状态栏，以及共享弹窗表面。保留现有 Git 操作、快捷键、列定制和分栏拖动。

## 视觉方向

采用 Apple 桌面工具的层级：导航在后，文档在前，主操作清楚。使用系统字体与系统强调色，避免大面积装饰、渐变卡片和占用文档空间的巨大留白。

| 元素 | 规则 |
| --- | --- |
| 内容画布 | 原生文本背景色，代码区不使用透明材质 |
| 文件表格 | 实色背景，不在空白区域绘制交替条纹；状态徽标提供扫描线索 |
| 导航与工具栏 | 中性灰原生材质；减少透明度或增强对比度时使用实色 |
| 分区标题 | 12pt semibold，16pt 图标槽，34pt 标准行高 |
| 工具图标 | 16pt medium，主操作热区 32×28pt；仅图标模式隐藏文字 |
| 次级图标按钮 | 24pt 行高，对比工具保留 22×24pt 一致尺寸 |
| 仓库行 | 28pt，选中后文字、图标和计数同步反色 |
| 数量徽标 | 10pt semibold 等宽数字，18pt 最小高度 |
| 输入框 | 实色背景、细边框、6pt 圆角；提交编辑器内边距 10×9pt |
| 圆角 | 窗口及弹窗 8pt，控件 4–6pt |
| 强调色 | 系统 accent；红绿保留差异及状态含义 |

## 交互规则

- 悬停轻微显露按钮热区，按下立即反馈，不添加延时和阻断操作的动画。
- 仓库切换及列表更新不添加淡入淡出。
- 不改变原生滚动、分栏拖动和严格差异行对齐。
- 默认不把焦点放入输入框，继续使用既有 Tab 导航与 Esc 取消。
- 保留贮藏应用的单一组合按钮、状态筛选的无背景图标，以及 AI 提交说明入口。
- 弹窗维持已验证的原生呈现和关闭机制，避免重新引入遮罩及圆角过渡问题。
