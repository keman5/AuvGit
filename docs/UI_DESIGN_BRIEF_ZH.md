# RayGit 原生 macOS UI 设计功能概要

以下内容可直接复制给设计 AI。请为 RayGit 设计完整的原生 macOS 桌面 Git 客户端 UI，保留下列已有功能，重构视觉与信息层级，不以减少功能换取简洁。
本概要依据当前原生应用源码与功能文档整理；功能存在不等于全部真实远端与全部视觉状态已经验收。

## 1. 产品定位与设计边界
- RayGit 面向需要在多个本地仓库中查看、编辑、暂存、提交、追溯历史和解决冲突的开发者。
- 平台为 macOS 14+；遵循桌面应用的窗口、菜单、工具栏、分栏、右键、键盘和原生文件选择习惯。
- 参考 SmartGit 的专业工作流与信息密度，形成 RayGit 自己的视觉语言；不要复制专有图标或资源。
- 核心体验是“仓库 → 文件状态 → 差异 → 编辑/暂存 → 提交”，历史与冲突处理同等重要。
- 需要专业、清晰、紧凑且长时间使用舒适；减少大卡片、装饰性留白和重复按钮。
- 原生应用和仓库内 `plugins/raygit` 是独立界面产品：插件的 MCP 工具、浏览器面板、AI 上下文和插件命令配置不是原生应用页面。
- 此次仅设计原生 macOS 应用；不要加入 AI 聊天侧栏、MCP 控制台、网页导航或插件安装页。
- 原生“Git Flow 与托管平台”设置仅提供已有工作流与打开外部审查网页，不是内置 PR 管理系统。

## 2. 全局结构与导航
- 主窗口顶部为可自定义原生工具栏，包含打开、创建、刷新、仓库名称、仓库工具、Fetch、Pull、Push、提交、贮藏、新建分支、语言。
- 保留工具栏自定义与溢出能力；常用操作可见，低频操作进入菜单，窄窗口仍能访问。
- 左侧为仓库与引用侧栏，右侧切换“工作区 / 历史”，底部为全局状态栏。
- 左侧仓库区与分支区可调整比例；主内容分栏也可拖动，面板独立滚动。
- 工作区主要包含文件列表、差异预览、紧凑历史、提交编辑四个区域。
- 完整历史主要包含提交图与提交列表、选中提交的变更文件列表、文件差异。
- 项目终端可在主内容下方展开，保持侧栏、文件、差异和提交操作可用。
- 文件比较、提交详情使用独立窗口；设置使用独立窗口；创建、网络、标签、仓库工具、活动记录使用任务面板或 sheet。
- 已打开仓库、当前仓库、最近仓库和可关闭的仓库会话需要清楚区分；不强制将现有侧栏改成浏览器标签风格。
- 切仓库及重新启动时恢复已有会话、选择、过滤、视图状态和提交草稿；设计不能隐含丢弃草稿。

## 3. 欢迎页与仓库管理
- 无仓库时显示产品名称、简短说明、打开本地仓库主按钮和快捷键提示。
- 最近仓库显示名称，长路径以辅助信息或提示提供；当前仓库显示分支与选中状态。
- 仓库右键：打开、在 Finder 显示、复制路径、从最近列表移除；移除记录不删除文件。
- 创建仓库面板支持初始化新仓库与克隆现有仓库两种模式。
- 克隆输入 URL 或本地来源路径；两种模式均输入/选择目标目录，显示校验、进行中和失败信息。
- 处理路径不存在、无访问权限、非 Git 仓库、克隆失败等状态，提供明确恢复动作。

## 4. 分支与贮藏侧栏
- 分组显示本地分支、远程分支、贮藏；当前分支必须独立标记，不能仅靠颜色。
- 本地分支单击选择，双击/Enter 请求检出；右键提供检出、日志、重命名、安全删除、复制名称。
- 远程分支提供日志和复制；可通过仓库工具创建跟踪分支或设置上游。
- 新建分支支持名称输入；从提交创建分支与工具栏创建分支要体现是否会切换分支。
- 贮藏显示说明与引用，双击查看独立差异；支持保存、应用、删除、重命名和指定路径贮藏。
- 检出、应用、删除等确认必须显示发起操作的仓库与目标，避免切仓库后目标混淆。
- 当前分支不能删除；安全删除失败应说明未合并等原因，不伪装成成功。

## 5. 工作区文件面板
- 列表显示文件名、索引状态、工作区状态、相对目录，清晰区分同一文件同时有两类改动。
- 覆盖修改、新增、删除、重命名、未跟踪、未合并等状态；提供图标/文字与颜色组合。
- 支持路径筛选、列表/目录树切换、Cmd/Shift 多选，显示选中数量与可执行动作。
- 单击联动差异；双击/Enter 默认打开独立比较，设置可改为暂存/取消暂存。
- 文件右键：系统打开、Finder 显示、文件比较、文件历史、暂存、取消暂存、丢弃、复制名称/绝对路径/相对路径。
- 多文件操作仅作用于符合条件的选中集合；单文件专用动作禁用。
- 空白处右键提供全部暂存/全部取消暂存，不对旧选择偷偷执行操作。
- 目录树还支持重命名、移入废纸篓、恢复本次移除文件、忽略路径、编辑 .gitignore、查看已忽略文件。
- 丢弃说明覆盖已跟踪文件的未暂存改动；不删除未跟踪文件，不覆盖索引，冲突文件不能使用普通丢弃。
- 空态区分工作区干净、过滤无结果、无选择、目录加载失败。

## 6. 差异预览与提交面板
- 差异预览显示文件/比较范围；可切换工作区与已暂存差异，支持忽略空白。
- 支持并排和统一补丁、行号、块导航、基础语法高亮与字符级差异。
- 明确显示新增/删除/修改及没有内容差异的状态，提供“编辑 / 三栏对比”入口。
- 提交面板包含已暂存数量、完整提交消息编辑、修订上次提交、Signed-off-by、提交模板入口。
- 主按钮明确为“提交已暂存内容”或“修订提交”；修订显示风险提示并确认。
- 无消息、无可提交内容、运行中或仍有冲突时禁用提交，并解释原因。
- 提交成功、失败、草稿保留应可感知；历史刷新不能清空正在编辑的消息。

## 7. 完整历史、提交详情与检查页面
- 提交列表显示拓扑图、提交说明、引用标记、作者、日期、短 ID；合并关系与当前引用可追踪。
- 支持提交说明/正文搜索、作者过滤、按提交 ID 跳转与分页加载更多。
- 文件历史跟随重命名；分支历史和文件历史显示范围条与“显示全部历史”。
- 单击提交联动变更文件及差异；双击/Enter 打开独立提交详情窗口。
- 提交详情显示完整消息、提交 ID、作者/日期与变更文件，可复制提交 ID 和消息并查看所选文件差异。
- 提交右键：详情、复制 ID/消息、创建分支、创建标签、分离 HEAD 检出、摘取、还原。
- 合并提交摘取/还原已有主线父提交选择；不要沿用旧文档中“完全不支持”的描述。
- 参考版本比较页：左右引用输入、变更文件列表、统计和所选文件差异。
- Blame 页：行号、作者、日期、提交、代码；可复制代码并打开对应提交。
- Reflog 页：引用、作者、日期、提交、动作；可复制记录并打开提交。
- 历史空态区分无提交、搜索无结果、范围无提交、尚未选择文件以及加载失败。

## 8. 独立文件比较与编辑窗口（重点）
- 顶部必须清楚呈现仓库、相对路径、当前模式、版本关系、可编辑位置和未保存状态。
- 普通文本默认按状态布局：未暂存为索引→工作区双栏；仅暂存为 HEAD→工作区双栏；两类改动同时存在为 HEAD / 工作区结果 / 索引三栏。
- 用户可切双栏、三栏、补丁；保留草稿、光标与撤销历史，不能因布局切换重新加载文本。
- 三栏编辑结果居中；HEAD、索引与其他参考版本只读，工作区/结果才可编辑。
- 每栏有版本标题、只读/可编辑标识、行号、独立滚动与可拖动分隔；参考栏不呈现输入框外观。
- 支持搜索匹配、上/下匹配、修改块跳转、同步滚动、换行、行号开关、原生复制粘贴、撤销重做。
- 行号小于代码且弱化；代码等宽；基础高亮和字符差异不能破坏文字可读性。
- 行级差异使用弱底色，字符级使用更强底色；新增绿、删除红、修改橙，深浅主题分别校准。
- 修改块可接受指定版本；“采用完整版本”与“接受此块”必须在位置、文案和确认上区分范围。
- 保存仅写工作区；保存并暂存、逐行/逐块暂存、取消暂存是独立操作，避免“保存=提交”的暗示。
- 补丁模式提供行/块选择与暂存/取消暂存；未保存草稿需先保存，权限变化/空文件使用整文件操作。
- 支持建立重命名关系、恢复删除文件版本、明确选择解码、编码转换与换行规范化。
- 图片比较支持选择两个已有版本、并排/透明叠加、尺寸与字节数；二进制不要显示伪编辑器。
- 大文本进入只读分页；超大 UTF-8 文本进入流式查看，提供页导航、版本选择和只读原因。
- 不可编辑状态包括未知编码、未规范化混合换行、符号链接、非普通/只读文件和超限文本；解释原因和可用动作。
- 外部比较/合并可选版本和工具；外部结果先显示待应用，再由用户确认应用到草稿并显式保存。

## 9. 冲突解决器（重点）
- 默认 Ours / 编辑结果 / Theirs 三栏；支持 Ours+结果、全部三栏、结果+Theirs，左侧可显示共同祖先。
- Ours/Theirs 要配合版本信息解释，尤其 rebase 场景不能简单标为“我的/对方的”。
- 开窗保留原工作区与冲突标记，不自动采用一方、不自动合并或覆盖草稿。
- 当前冲突工具区显示块序号、结果行范围、未解决状态、上一个/下一个冲突。
- 支持当前块采用 Ours、Theirs、Ours 后 Theirs、Theirs 后 Ours；有基准段时可采用 Base。
- 结果栏边缘提供清楚的左右接受箭头；作用于当前块，保留块外内容并支持撤销。
- 当前实现以整块橙色背景、当前块边框和侧轨突出未解决范围；我方蓝色、对方紫色内容底与接收箭头对应，字符差异层级更强，同时保留文字/标记提示。新设计可重设配色，但必须清楚对应来源、当前块及未解决状态。
- 不完整冲突标记显示修复说明并禁用块选择；仍有标记时禁止标记解决。
- “自动合并”仅生成待编辑草稿；“采用完整版本”替换全文，覆盖未保存草稿前确认。
- 主完成动作是“保存并标记解决”；单独保存不暂存、不代表冲突已解决。
- modify/delete 冲突可恢复指定版本后解决，也可明确确认以删除解决。
- 保存前发现外部修改应保留草稿并阻止覆盖；提供重新加载等恢复路径。

## 10. 网络、标签与高级仓库工具
- 网络面板支持 Fetch、仅快进 Pull、Push 预览与确认执行，显示真实阶段/百分比和可取消状态。
- 预览过期需重新预览；最终成功依实际推送结果，不把预览显示为已推送。
- 显示安全的凭据助手名称及配置系统钥匙串入口；不显示密码/令牌，SSH 使用已有环境。
- 无远程、无上游、认证失败、连接失败、超时、取消分别呈现可理解的结果。
- 标签管理显示名称、目标提交、注释；支持轻量/注释/签名标签创建、拉取、推送预览、本地删除、远端删除预览与确认。
- 仓库工具分“检查 / 更改”，提供参数、说明、结果、运行状态；危险操作单独确认。
- 保留远程查看/添加/移除、设置上游、创建跟踪分支、ahead/behind、push dry-run 与 force-with-lease。
- 保留 Merge、Reset soft/mixed/hard，以及 merge/rebase/cherry-pick/revert 的继续/中止。
- 保留交互式 Rebase：选择基准、加载拓扑计划、编辑 todo、相关完整提交消息、预览计划与显式 exec 命令、确认执行。
- 保留子模块查看/初始化更新/添加、Git LFS 状态/本仓库初始化/追踪规则、提交模板与本仓库签名配置。
- Git Flow 支持 feature/release/hotfix 的开始与完成、主/开发分支配置；审查入口打开外部页面。
- 可优化高级工具的分类与导航，但不能用无功能占位控件替代现有操作。

## 11. 终端、活动记录与设置
- 内置终端位于主窗口底部；Command+反引号切换并聚焦，隐藏保留 shell 与滚动内容。
- 每仓库独立会话；支持会话菜单、关闭、重启已退出 shell、会话上限提示；隐藏与终止必须有不同图标/文案。
- 保留 ANSI、选择复制粘贴、Ctrl-C、尺寸变化；终端展开时提交表单独立滚动，不挤出核心控制。
- 活动记录独立入口显示操作结果，错误文本可复制；不要与终端混为一项。
- 设置采用可搜索分类：通用、外观、编辑器、历史、命令与 Git、网络与认证、外部工具、快捷键、Git Flow 与托管平台、更新、隐私、高级。
- 通用：启动恢复、默认工作区/历史、文件双击、路径筛选大小写；历史：分页条数、日期格式。
- 编辑器：字体字号、Tab 宽度、行号、换行、同步滚动、默认布局、当前行、不可见字符、高亮/字符差异、差异颜色与恢复默认。
- Git：可执行路径与验证、超时、消息清理；全局身份与签名明确标注全局作用及仓库覆盖关系。
- 网络：继承/覆盖代理、URL 校验、SSH 命令、Fetch prune；外部工具：路径、参数模板、草稿校验与应用。
- 快捷键支持打开/刷新/暂存/提交的 Command 字母配置及冲突提示。
- 更新：可信 HTTPS manifest、手动检查、版本说明、下载链接；隐私：确认清除最近记录或会话/草稿。
- 高级：后台刷新开关与轮询间隔；恢复默认按分类执行；搜索无结果提供清除搜索。

## 12. 全局状态、主题与交付要求
- 深色、浅色、跟随系统三种主题；简体中文、繁體中文、English、日本語和跟随系统。
- 四语切换即时生效且保留仓库、选择、提交/编辑草稿与终端；为英文/日文较长文字预留空间。
- 路径、代码、提交内容、Git 原始错误保持原样；界面文字本地化，日期按设置与语言显示。
- 提供默认、悬停、按下、焦点、选中、禁用、加载、成功、失败、空态、未保存、过期预览等组件状态。
- 运行中显示操作名称，禁用冲突写操作；加载不让旧选择结果覆盖新选择，不清空草稿。
- 窗口关闭、重新加载、退出保护未保存编辑；保存失败保留草稿，危险确认明确目标与后果。
- 用颜色之外的图标/文案传达状态；保证键盘导航、焦点环、文字对比、可点击区域与可访问名称。
- 请交付全局信息架构、完整页面清单、关键任务流程、深浅主题高保真稿、组件/字号/间距/颜色规范及交互标注。
- 必须覆盖：欢迎、工作区干净/多状态/过滤、多选、历史搜索/详情、两栏与三栏编辑、冲突完整/残缺/完成、图片/大文本、终端、全部设置分类、网络、标签、Rebase 与危险确认。
- 提供约 1050×750 与 1440×900 的桌面布局，并标注窄窗口、长路径、长分支名、长翻译、终端展开时的折叠/溢出策略。
- 每个主要页面标注主动作、次动作、上下文菜单、快捷键、加载/错误/空态及内容溢出规则；不要只交付单张漂亮主页面。
- 设计若提出新增能力，请另列为建议，不能标成当前已有；禁止删除上述功能或将原生产品设计成插件网页。
