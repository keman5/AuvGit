# SmartGit UI 与交互复刻

2026-10-03 对照本机 SmartGit 26.1 的实际工作区、文件上下文菜单、文件双击窗口、提交和分支上下文菜单实现。保留现有四语言及原生macOS外观，不复制专有资源。

## 布局

- 顶部：带图标和文字的 Fetch / Pull / Push / 提交 / 暂存 / 取消暂存 / 丢弃 / 贮藏 / 分支工具栏。
- 左侧上部：仓库列表；下部：本地分支、远程分支、贮藏。分隔条可拖动。
- 右侧上部：名称、索引、工作区、相对目录；中部：差异；下部：紧凑提交图与提交说明编辑器。
- 完整历史视图保留，支持文件或分支范围，明确显示过滤范围并可回到全部历史。

## 行为清单

| 对象 | 单击 | 双击 / Enter | 右键菜单 |
| --- | --- | --- | --- |
| 文件 | 选择并预览差异，暂存独有变更自动选择索引 | 独立文件比较窗口 | 打开文件、Finder、显示变更、日志、暂存、取消暂存、丢弃、复制名称/路径/相对路径 |
| 多个文件 | 原生Cmd/Shift多选 | 不执行单文件比较 | 暂存/取消暂存作用于符合条件的集合；单文件功能禁用 |
| 文件列表空白 | 保持原生选择规则 | 无操作 | 只提供全部暂存/取消暂存，避免对旧选择执行行操作 |
| 提交 | 选中；完整历史视图联动文件和diff | 独立提交详情与文件diff窗口 | 详情、摘取、还原、创建分支、创建标签、检出为分离HEAD、复制ID/消息 |
| 本地分支 | 只选中 | 请求检出确认 | 检出、日志、重命名、安全删除、复制名称 |
| 远程分支 | 只选中 | 显示分支日志 | 日志、复制名称 |
| 贮藏 | 只选中 | 独立差异窗口 | 显示变更、确认应用、确认删除 |
| 最近仓库 | 打开仓库 | 同打开 | 打开、Finder、复制路径、从最近列表移除（不删除仓库） |
| 历史变更文件 | 预览对应diff | 独立文件比较窗口 | 显示变更、复制相对路径 |

## 正确性与范围

- 使用原生 Table/List 的 selection contextMenu 和 primaryAction；右键目标与主选择解耦。
- 丢弃会覆盖未暂存修改，确认框说明不可撤销；不删除untracked、不覆盖索引、拒绝冲突文件；所有路径先校验后写入。
- 分支删除使用Git安全 `-d`；没有force-delete。从历史创建分支不隐式切换，从工具栏创建分支会切换。
- 摘取/还原要求干净仓库，合并提交菜单禁用。遇冲突停止并显示Git错误；完整冲突解决/继续/中止GUI仍待后续。
- 确认及名称对话框绑定发起仓库；期间切换仓库不会向新仓库执行旧操作。
- 文件历史跟随重命名，并在完整追踪后分页，避免Git跳过rename后漏掉早期历史。超出现有32MB输出上限会报错。
- 独立窗口绑定创建时的仓库和文件/提交；关闭释放控制器。加载结果防止过期选择覆盖。
- 新增菜单支持简中、繁中、英、日。主窗口保留即时语言切换。
