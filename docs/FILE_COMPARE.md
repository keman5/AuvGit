# 文件比较器：编辑与三栏对比

2026-10-03 增量实现。保留原有多语言、独立历史窗口与工作区操作。参考本机 SmartGit 26.1 独立文件比较器的完整文件内容、重新加载、忽略空白、行号、同步滚动等入口。

## 入口与布局

- 双击工作区文件、右键“文件比较”，或点击差异栏“编辑／三栏对比”，打开独立比较器。
- 默认三栏：HEAD、索引、可编辑工作区；即使文件只在一个版本存在，也保留明确的缺失提示。
- 双栏：HEAD或索引作为只读基准，右侧编辑工作区。
- 冲突文件：我们的版本／工作区合并结果／他们的版本；可将左栏切为共同祖先。
- 补丁视图保留并排／统一模式，显示磁盘中的已保存内容，未保存草稿会有提示。
- 历史与stash对比仍为只读补丁，不允许误写历史版本。

## 编辑与保存

- 原生NSTextView完整文本编辑、系统复制粘贴、独立撤销重做；行号在独立边栏，不进入保存内容或代码复制。
- 双栏／三栏切换复用工作区文本视图，保留编辑草稿、光标及撤销历史。
- “采用完整版本”只替换内存草稿，可撤销；需要显式保存才写磁盘。
- ⌘S／保存只写工作区，不暂存。“保存并暂存”是独立动作。
- 冲突文件需要删除冲突标记后执行“保存并标记解决”，才会git add。
- 关闭有草稿的窗口或退出应用时，提供保存、放弃草稿、取消；保存失败保留窗口和草稿。
- 重新加载有草稿时必须确认。保存比较初次读取的精确字节与当前磁盘字节，发现外部修改则拒绝覆盖。
- UTF-8 BOM与统一CRLF格式会保留；文件可执行权限也会保留。文本末尾是否换行由编辑内容控制。
- 混合CRLF/LF、非UTF-8、二进制、符号链接、非普通文件、只读文件及超过2MB的文件不能编辑。不会沿符号链接写仓库外路径。
- 不存在于工作区的文件本轮不支持从编辑器重建。删除/修改类冲突因此可能需要外部工具处理。

## 浏览控制

- 可拖动分栏、行号、自动换行、同步滚动、搜索高亮和上下匹配跳转。
- 顺序敏感的行差异标记和变更块导航，覆盖重复行、多空行、移动、末尾换行差异。
- 同步滚动依据未变行锚点和修改区插值；不向可编辑文本添加虚拟空行。
- 原补丁视图新增搜索及匹配数、自动换行、行号、同步滚动和字体大小选项。
- 全部新界面文案包含简体中文、繁體中文、English、日本語。

## 实施与验证

三个 GPT-6.1-sol agent 分别实现Git内容/保存核心、多栏编辑surface及行差异算法、补丁视图增强；主代理负责窗口生命周期、草稿保护、工作区联动、本地化和集成。

临时仓库测试覆盖三个版本各异、保存不改变索引、外部修改保护、BOM/CRLF、混合换行拒绝、重命名、可执行权限、只读和大文件、冲突stage读取及显式解决。创建可交互验收仓库：

```sh
python3 scripts/make-compare-demo.py
```

该仓库同时含 Editor.swift 的三个不同版本与 Conflict.txt 的真实合并冲突，可安全用于编辑验收，不关联生产远端。

## 明确边界

本轮没有语法/字符级高亮、逐块/逐行暂存、每块左右接受箭头、自动三方合并算法、任意文件或任意引用选取、编码转换。修改区滚动为估算映射，开启自动换行后不保证像素级行内对齐。大范围不同内容超过算法阈值时保守高亮整个未解析区域，不声称每行都不同。保存检查不是跨进程文件锁；没有整个外部进程组取消机制。
