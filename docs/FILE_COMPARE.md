# 文件比较器、部分暂存与网络任务

2026-10-03 实现。比较器使用完整文件版本与独立原生文本编辑器；历史和 stash 对比保持只读。

## 入口与布局

- 双击工作区文件、右键“文件比较”，或点击差异栏“编辑／三栏对比”，打开独立比较器。
- 默认三栏：HEAD、索引、工作区；双栏可选择 HEAD 或索引作为基准。
- 冲突文件：我们的版本／工作区合并结果／他们的版本；左栏可切为共同祖先。
- 图片版本存在时自动展示 HEAD、索引、工作区并排图片，或 HEAD／工作区透明叠加。PNG/JPEG 等由 NSImage 解码，显示尺寸和字节数。
- 大文本（超过 2 MB、最多 32 MB）自动进入只读分页。每页最多 500 行，单个超长行仍按最多 100,000 UTF-16 单元分段，避免一次排版全部内容。冲突文件分页展示 base／ours／theirs／worktree。
- 超过 32 MB 的工作区 UTF-8 文件进入真正流式只读查看：FileHandle 每页只读约 128 KB、最多 500 行，超长行按字节边界分段，UTF-8 多字节字符不截断。以文件大小、修改时间和 inode 验证快照，发现外部修改要求重新加载。
- 补丁页提供按行、按块暂存／取消暂存；操作前必须保存草稿。

## 编辑、接受与合并

- 原生 NSTextView 编辑、复制粘贴、撤销重做；独立行号边栏不进入保存内容或代码复制。
- 双栏／三栏切换复用文本视图，保留草稿、光标和撤销历史。高亮使用临时属性，不修改文本和撤销记录。
- 在可编辑栏的修改块上右键，选择“接受此块：某版本”，将该版本的对应块应用到当前编辑草稿。插入／删除块也支持接受；末尾删除可在前一行使用菜单。
- “采用完整版本”替换内存工作区草稿，仍需显式保存。
- 索引栏可编辑，保存索引草稿更新索引版本；工作区草稿保存只写磁盘。“保存并暂存”是独立动作。
- 冲突的“自动合并”使用 `git merge-file -p --diff3` 对临时副本合并，只返回草稿。没有修改真实工作区或索引。冲突会保留明确的 ours／base／theirs 标记，用户编辑并保存后再标记解决。
- 重新加载、关闭窗口、退出应用时保护未保存草稿。保存失败保留草稿。保存前比较精确字节，检测外部文件修改。
- UTF-8 BOM、统一 CRLF、文件可执行权限保留。UTF-16 BOM 可以解码查看，明确只读；不自动转换编码。
- 二进制、未知编码、混合换行、符号链接、非普通文件、只读文件、超过 2 MB 文本不能编辑；不会沿符号链接写仓库外路径。

## 浏览与外部比较

- 可拖动分栏、显示行号、自动换行、同步滚动、搜索高亮、匹配和修改块跳转。
- 修改行配对后提供字符级差异，UTF-16 范围保持完整 Unicode 字符；超出详细算法阈值时保守标记变化区。
- Swift、JS/TS、Go、Python、JSON、shell、C/C++、Rust 基础词法高亮支持关键词、字符串、注释和数字。补丁并排视图同样显示字符差异与基础高亮。
- “外部比较”菜单可选择左右版本（含冲突阶段），选择工具后保存工具路径，后续直接启动。通过参数数组传递临时只读副本，不经过 shell，不写仓库文件。兼容接收两个文件路径的可执行文件／应用；未知工具若需要专用参数，暂未提供参数模板。
- 简体中文、繁體中文、English、日本語提供新界面文案。

## 网络任务与凭据

- 网络面板支持 fetch、仅快进 pull、push dry-run 预览和确认后实际推送。进度来自 Git stderr 的真实阶段／百分比，未报告百分比时显示阶段文本。
- push 预览绑定仓库路径、引用与分支／远程／push 配置摘要；执行前状态变化会要求重新预览。远端在预览后仍可能改变，Git 的最终推送结果才是成功依据。
- 取消会传递到真实 Git 子进程组，先 TERM 后 KILL；超时保留 120 秒默认。进程组在 spawn 时设置，使用 close-on-exec 防止并发任务互留管道，信号完成后才回收 leader 以避免 PID 复用。
- 显示已配置凭据助手的安全名称；自定义助手内容可能含秘密，仅显示通用标签。可确认将当前仓库本地助手设为 osxkeychain；不读取密码或令牌。
- SSH 使用用户已有配置和 agent；已有 GIT_SSH_COMMAND 保留。未配置时采用 BatchMode，交互凭据提示关闭。GUI PATH 补充标准 Homebrew 目录，缺 Git LFS 时给出可操作提示，不自动安装。

## 验证与边界

`AdvancedDiffTests` 的 10 项测试已通过，覆盖逐块接受、重复／移动行穷举重构、Unicode 字符范围、词法范围、UTF-16、分页和干净／冲突三方合并。`GitProcessTests` 的 6 项测试已通过，覆盖取消后真正终止 TERM-resistant 子进程、已取消任务不启动、超时与真实 stderr 进度、并发管道隔离、凭据助手不泄露、push dry-run 不改临时裸仓库及真实推送更新引用。后续全集和 UI 验收由主代理统一执行。新增 `StreamingComparisonTests` 覆盖超过 32 MB 的按块读取、跨页 UTF-8／超长行、BOM／行分页、外部修改及符号链接拒绝；这些新测试尚待主代理统一运行。

可交互验收仓库：`python3 scripts/make-compare-demo.py`。包含三个版本各异的 Editor.swift 和真实 Conflict.txt，不关联生产远端。

明确限制：超过 32 MB 的 HEAD／索引／冲突阶段历史 blob 尚未流式导出或查看，界面明确仅流式读取工作区。2–32 MB 分页仍是内存快照的限量排版；超过 32 MB 工作区是按需 FileHandle 读取。超大 UTF-16、未知编码和二进制需要外部查看器。同步滚动按锚点插值，自动换行时不保证像素级对齐。基础词法高亮不等同编译器解析（补丁跨行注释可能不连续）。未知编码没有转换界面。图片叠加固定 HEAD／工作区，冲突图片阶段可交给外部工具比较。不存在于工作区的文件不支持从比较器重建；删除／修改冲突需要其他文件操作。保存检查不是跨进程文件锁。真实远程服务认证和用户选定外部比较工具还需用户环境验收；本地裸仓库测试不能代替远程验收。
