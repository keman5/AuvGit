## 集成约束

- 使用当前工作目录，不创建 worktree；保留用户数据及其他工作。
- 保留上一轮五项 bug 修复；新功能不得撤销外部变更检测、路径保护和原生撤销。
- 临时测试仓库及未显示的 AppKit 组件；不激活应用、不将测试窗口置前。
- 所有构建和测试经 `scripts/build.sh` 执行。并行实现完成后统一编译，避免共享 SwiftPM 缓存被同时操作。

## 用户入口与实际行为

- 比较窗口的比较选项菜单提供独立保存索引、保存活动副本到工作区、忽略空白／大小写／换行、当前文件语言和强制比较。编辑器右键提供接受行／选区／行内变化及对应的暂存、取消暂存。索引操作重新核对快照，保留未选内容和原有可执行权限。
- 冲突布局可选择结果下置；Base 可打开单独比较窗口，包含搜索和变更导航。紧凑视图保留底层原生编辑器，返回完整视图继续编辑时保留草稿、光标和撤销。紧凑视图自身仍是只读投影。
- 独立日志窗口可以选择两个提交，或选择工作区／索引虚拟节点，联动文件集合、预览和独立比较；方向可反转。按后续界面反馈，主窗口日志恢复为纯提交列表，移除虚拟行和底部文件条；选择提交保持工作区文件列表与预览，查看变更进入独立日志窗口。
- 提交图支持隐藏祖先桥接、投影引用的 `~` 标记、分页边界、逐个合并路径折叠和展开。虚拟节点不会作为真实 Git 提交执行命令。
- 图谱显示菜单提供作者／提交者、头像、姓名、邮箱、日期、SHA 和 Overlap 列；设置会记忆。主窗口可叠加一个辅助分支。签名和上游状态通过符号及说明表达，不只依赖颜色。
- 拖动提交、HEAD 或本地分支后先展示来源、目标和操作预览。确认时重新核对仓库和对象身份；分支移动拒绝已在工作树检出的分支，Cherry-pick 的目标限定为当前 HEAD，选择提交进行 Rebase 要求连续且结束于 HEAD。

## 资源边界与验收边界

- 强制比较按文件显式启用，合计解码文本最多 16 MiB、每个版本最多 100,000 行、单行最多 256 KiB。超出普通编辑阈值时保持只读；异步校验可以取消，重载／重新解释编码会使旧校验失效。超限文本继续使用既有分页或流式查看。复杂无锚点大段允许保守比较，不改变普通精确比较。
- 混合换行文件保留既有写入保护；统一换行格式通过原始格式参与差异规则，不改写文件字节。
- 签名标识表示提交对象包含签名，显示“已签名（未验证）”；不会启动 GPG／SSH 验证器，也不会把存在签名描述为验证成功。
- Overlap 是实际补丁中文件及原始修改行位置的重叠提示，最多分析选中项附近 80 个候选并缓存。不同父版本的行号可能偏移，因此它不是 Rebase 是否冲突的保证，也不是 SmartGit Git-Flow 工作流分析的完全等价实现。
- 提交／索引端点的重命名识别使用 Git `-M`；未跟踪工作区路径的补充识别只匹配内容完全相同的重命名，其余按增删或修改显示。
- 本轮验收不激活任何测试窗口；组件几何、编辑、图谱和临时仓库操作均在后台测试。没有进行 SmartGit 与 AuvGit 双应用前台逐像素对照，也没有进行真实远程认证测试。
