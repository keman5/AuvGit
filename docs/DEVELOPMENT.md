# 开发约定

## 组件测试必须在后台运行

组件测试默认在后台执行，不得干扰用户正在使用的前台应用。此约定适用于开发者、AI agent、测试脚本和原生 AppKit／SwiftUI 组件测试。

- 通过终端或测试脚本执行，输出写入日志；不能仅以命令是否放入后台判断是否满足要求。
- 不激活测试应用、不将测试窗口置前、不抢焦点、不切换当前前台应用或桌面空间，也不向前台应用发送模拟键盘、鼠标或剪贴板操作。
- 原生组件优先使用离屏窗口进行布局、绘制和状态断言；避免调用会激活应用或窗口的接口，例如 `NSApp.activate`、`makeKeyAndOrderFront`、`orderFrontRegardless`。
- 必须依赖真实前台焦点、系统键盘或鼠标的测试，在独立登录会话或虚拟机中执行。没有隔离环境时，跳过这些用例并明确记录原因，不得将它们报告为已通过。
- 测试期间保持用户当前应用、窗口和输入焦点不变；测试完成后清理自己创建的测试窗口与进程。
- 只有用户明确要求前台交互验收时，才执行会操作前台窗口的独立验收流程；常规组件测试不能隐式包含此流程。
