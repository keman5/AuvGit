# 首选项

参考检查覆盖 SmartGit 26.1 的仓库重新打开、工作区/日志默认视图、主题与语言、日期显示、文件双击、路径搜索大小写、提交消息策略、后台刷新、Git 可执行文件与配置、编辑器、快捷键、外部工具和代理。AuvGit 按自身实际能力提供可搜索分类，未声称与 SmartGit 逐项完全等价。

## 主框架与本地设置

- 使用 12 类侧栏，默认窗口 860×660，可调整大小。搜索同时匹配分类名及代表性设置关键词；无匹配时显示空状态和清除搜索按钮。
- 通用：默认重新打开上次仓库。关闭后保留已存会话和草稿；明确的 `--repo` 参数仍会打开目标仓库。新仓库可默认显示工作区或历史，已有保存状态优先。
- 外观：系统/浅色/深色实际更新原生应用外观；保留英文、简体中文、繁体中文和日语选择。
- 文件：默认双击比较，可改为暂存未暂存文件或取消已完整暂存文件。状态列表与目录树采用相同行为；未改动文件和冲突始终比较。上下文菜单的比较不受双击设置影响。路径筛选支持忽略、精确和智能大小写；智能模式中含大写字母的查询精确匹配。
- 历史：每页提交数限定 25–1000，下次加载生效；相对日期、日期或日期时间由历史和提交详情共用本地化 helper，已打开视图观察设置变化。
- 高级：后台刷新开关同时约束文件系统通知与轮询。轮询间隔限定 3–300 秒，通知合并延时保持 350 毫秒；手动刷新和用户操作后的刷新仍有效。通用、外观、历史、高级恢复默认仅改变本分类。
- 快捷键、Git Flow/审查页面和更新页复用既有扩展设置的独立区块。更新检查由用户明确发起，使用配置的 HTTPS manifest。
- 隐私：清除最近仓库记录或会话/提交草稿均需确认，只处理本地应用记录，不删除仓库文件或 Git 提交。清除草稿包含当前提交草稿；当前仓库新视图状态随后继续正常保存。两项操作均不移除安全作用域书签。

## 编辑器与外部工具

编辑器设置使用 `editor.*` 本地持久化键，字体、字号、制表宽度、行号、换行、滚动同步、布局、当前行、不可见字符、语法/字符差异及差异颜色实际接入比较编辑器或只读补丁视图。已打开编辑窗口保留文本、草稿和撤销管理器；缺失字体回退系统等宽字体，字号限定 9–32，制表宽度限定 1–16。颜色默认采用随外观变化的语义系统色，支持恢复。

外部工具保留既有配置键，编辑值先保留为草稿，经校验并应用后才生效。参数采用 JSON argv 数组，不通过 shell 解析；占位符限定 `{left}`、`{right}`、`{base}`、`{result}`。工具处理临时副本，成功输出成为待确认结果，写回编辑草稿及保存仍遵循原有确认和预期内容检查。详细说明见 [EDITOR_PREFERENCES.md](EDITOR_PREFERENCES.md)。

## Git 与网络

Git 运行设置使用 `auvgit.git.{executablePath,timeout,commitCleanup}`，默认 `/usr/bin/git`、120 秒、default 清理策略。可执行路径通过实际 `--version` 验证；无效保存被拒绝。超时限定 5–3600 秒，对新 Git 进程生效。提交消息清理接入 `GitRepository.commit --cleanup`；default 省略参数以保留 Git 默认行为。

全局身份页读取 name/email、`gpg.format`、`user.signingkey`、`commit.gpgsign`。明确点击应用仅写改变的键，空值移除该键，保留未知配置；界面说明全局作用范围及仓库配置覆盖关系。签名格式及开关有实际配置消费者。

网络设置使用 `auvgit.network.{proxyMode,proxyURL,sshCommand,fetchPrune}`，默认为继承、空代理、空 SSH 命令、开启 prune。HTTP(S) 代理 URL 禁止内嵌用户名和密码；覆盖模式清理代理环境并仅给 AuvGit 子进程传递 Git `http.proxy`。界面说明仓库 URL 专用或 remote 配置可能覆盖，以及 SSH 代理需通过 SSH 配置处理。既有 `GIT_SSH_COMMAND` 优先。Fetch 的两个实际入口传递 `--prune` 或 `--no-prune`。凭据页不读取秘密，既有仓库凭据 helper 操作保留。恢复运行默认不改全局 gitconfig。

终端仍采用现有实现，未增加无消费者的终端配置分类。没有新增无实际效果的 diff 开关。
